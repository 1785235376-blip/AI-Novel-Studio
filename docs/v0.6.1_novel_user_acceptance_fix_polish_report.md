Pass 11 removes bare-PID termination authorization from normal cleanup. `stop()` now retains each complete identity record and calls one API per process:

```text
opens the exact process object with minimum query / synchronize / terminate rights
reads creation_time and executable from that same handle
binds the recorded run_id / role / PID / argv / lineage / port contract
strictly compares the final handle-bound identity
terminates through the same validated handle
waits bounded time
closes the handle
```

The numeric PID is used only to open the process object. It is not retained as later termination authority. `taskkill /T` and the legacy unverified `terminate_tree()` path were removed.

```text
TERMINATION MECHANISM = VERIFIED WINDOWS PROCESS HANDLE

BROAD DESCENDANT KILL = NONE
KILL BY PORT = NONE
KILL BY PROCESS NAME = NONE
```

If the process identity is missing, malformed, cross-run, changed, inaccessible or otherwise unverifiable, termination is rejected fail-closed. If the exact opened process object exits naturally before or during termination, the result is `ALREADY_EXITED`; the code never reopens the numeric PID and therefore cannot follow PID reuse to a new process.
