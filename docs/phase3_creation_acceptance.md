# Phase 3 小说创作验收门禁

统一执行命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify_phase3_creation.ps1
```

覆盖范围：

- 多候选创建、独立生命周期、采纳一个并拒绝其余候选。
- 失败或取消候选单独重试，以及非失败任务拒绝重试。
- 多候选批量取消和已完成候选保留。
- 轮询超时收口、SSE 断线轮询恢复和完整输出校准。
- 页面刷新恢复、命名空间隔离和无凭据持久化。
- 后端重启中断任务的安全失败与重新生成。
- 恢复草稿版本保护、冲突持久化、复制和手工合并。
- 章节版本历史与回滚基础契约。
- DS-v1.0 Token 检查和前端生产构建。

`-SkipBuild` 只用于本地快速重复执行；阶段退出必须运行包含生产构建的完整命令。
