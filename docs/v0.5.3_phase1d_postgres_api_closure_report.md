## Implemented

- Added advisory Finding API routes:
  - `POST /api/projects/{project_id}/continuity/checks`
  - `GET /api/projects/{project_id}/continuity/findings`
  - `GET /api/projects/{project_id}/continuity/findings/{finding_id}`
- API honors `ENABLE_CONTINUITY_RULES`; disabled checks return `DISABLED` with
  no findings and do not bypass the flag.
- Project isolation is enforced for finding detail.
- Character and finding-type filters are supported by list retrieval.
- Existing File repository/service and deterministic rule tests remain passing.

## Safety

not accept findings, mutate Canon, Character, Timeline, Memory, or Chapters.
