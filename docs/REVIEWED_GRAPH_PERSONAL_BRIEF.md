# Original reviewed Graph text to personal writing brief

This slice replaces manual copying for one bounded path: an existing, successful schema-3 Graph run with an original `human_review` node can supply the four declarative writing-brief strings to the existing personal composer in Template Library.

The Experimental workbench captures the same project/session/actor/branch context and supplies the existing strict Studio Graph client. The importer reads the run, original graph, run again and graph again; versions, project/scope, graph digest, schema, completion and original reviewed-draft output must agree. The original backend remains the review and private-output authority. Before replacing the four fields the UI rereads and compares the complete projection and pin. Late responses, inactive/reader changes and retained callbacks cannot adopt an obsolete preview. This does not introduce an endpoint, job, model call, template owner, external submission or plugin execution.

The package keeps a reference to project, graph version/digest, run version, review node and original text SHA-256. It also explicitly says content may be edited, publisher is not verified and there is no execution authority. These manifest fields are editable provenance references, not signed credentials or permissions. Author identity and license remain separate human inputs. Original preflight, confirmation, install, copy, edit and history remain unchanged. Manual pasted candidates still carry their original UNVERIFIED label.

## Limits

The direct reference path requires schema 3, a successful run and an original reviewed text output. Legacy schema-1/2 review outputs are not upgraded or relabelled; manual import remains available. It does not auto-find runs, execute AI, infer licenses, install templates or submit anything to an official market. Full browser, real model quality, fresh PostgreSQL acceptance, whole-product and release acceptance were not performed in this slice. The one real-owner fixture is manual text, not evidence of a live model run.
