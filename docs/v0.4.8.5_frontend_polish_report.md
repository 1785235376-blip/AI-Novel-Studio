## Problem cause

After `POST /api/novels` succeeded, `NovelHome` immediately updated the Zustand `novelId`. This correctly opened the Writer Workspace, but the header resolved the novel title from the React Query `['novels']` cache. The create response had not been inserted into that cache, so the new ID could not be resolved to a title until a later query refresh or page reload.

Backend, API, Context and PostgreSQL behavior were correct and required no changes.

## Cache fix

The create success callback now performs these operations in order:

1. Write the returned Novel into the `['novels']` query cache with `QueryClient.setQueryData()`.
2. Avoid inserting a duplicate if the same Novel ID is already cached.
3. Call `onCreated(novel.id)` to update Zustand and open the Writer Workspace.

The cache therefore contains the selected Novel before the workspace header renders. The fix performs no extra API request, does not invalidate the query, and does not reload the page.
