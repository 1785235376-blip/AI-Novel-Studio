## 4. Frontend Architecture Before

The React/TypeScript/Vite/TipTap application used Zustand and TanStack Query correctly, but `App.tsx` owned most shell and workflow composition. Three global CSS files implemented a hard-coded dark palette, raw geometry and few reusable primitives. Playwright had one stale PostgreSQL writer-flow and no screenshot/geometry suite.

## 5. Frontend Architecture After

The existing runtime stack remains. `frontend/src/ui/` now owns tokens, AppShell, ModuleSwitcher, ContextBar, primitives, module shell placeholders and deterministic fixtures. The real NOVEL workspace supplies its existing chapter tree, TipTap editor and AI inspector through the shared AppShell slots. No backend feature, schema or migration changed.

## 6. DS-v1.0

`docs/ui/design_system.md` is the UI constitution and source of truth. It freezes product principles, visual language, AppShell/module contracts, tokens, controls, surfaces, status language, conflict/revision semantics, accessibility, desktop behavior, visual regression and the Design System Change Request process.

## 7. Design Tokens

`frontend/src/ui/tokens.css` defines light-theme-ready color, typography, spacing, radius, border, shadow, layout, z-index, motion and Lucide icon tokens. New shared UI is checked for raw colors outside the token definition.

## 8. AppShell

One AppShell provides GlobalHeader, ContextBar, WorkspaceBody and StatusBar. WorkspaceBody provides LeftSidebar, MainWorkspace and RightInspector. Header/context/sidebar/inspector/status geometry is tokenized.

## 9. ModuleSwitcher

The fixed accessible tab contract contains NOVEL, IMAGE and VIDEO in one position and visual language. The latest ModuleSwitcher unit test verifies three tabs, selected semantics and IMAGE dispatch.

## 10. ContextBar

Workspace, Project, Storyline and Branch use a shared navigation surface. Production NOVEL consumes current runtime scope; the deterministic fixture uses approved stable labels.

## 11. Sidebar / Inspector

The common shell fixes sidebar and inspector relationships while allowing module-owned content. At narrow desktop widths the inspector may collapse without changing module identity.

## 12. Shared Components

Initial primitives include Button, IconButton, Badge, Panel and EmptyState. AppShell, ModuleSwitcher and ContextBar are shared semantic components. Lucide remains the only general icon provider. Future primitives are added only for real consumers.

## 13. Novel Workspace

The real NOVEL workspace uses AppShell while retaining TipTap, chapter tree, autosave/version state, AI generation, collaboration, conflict, revision, members, permissions, audit and ContextSnapshot behavior. Save actions still use the V0.5.7 single-flight/optimistic-concurrency path.

## 14. Image Workspace Contract

IMAGE has a shell-only visual asset sidebar, future canvas surface and inspector contract. Generation is disabled and explicitly described as unavailable. No Image Provider, MediaAsset pipeline or generation feature was added.

## 15. Video Workspace Contract

VIDEO has a shell-only Scene/Shot/Storyboard/Keyframe/Clip sidebar, future Shot Canvas/Timeline surface and inspector contract. Generation is disabled. No provider, renderer or timeline engine was added.

## 16. Canonical References
