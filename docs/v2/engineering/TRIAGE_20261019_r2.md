# Round-2 failure triage — Windows development-host reality (2026-10-19)

Round 1 executed the complete File-backend suite on this Windows host and reported
**10089 passed / 190 failed / 14 errors / 4866 skipped** (two isolated shards). This
round classifies every one of those 203 failed/error node ids, fixes the defects that
are real product or portability bugs, and records the genuine platform limits instead of
silently skipping them.

Round-1 evidence is retained unchanged: `evidence/20261019-r1/backend-file-summary.md`.
The full suite was **not re-run end to end** in round 2; instead every previously failing
test file was re-executed under its required profile. Results below are from those runs.
