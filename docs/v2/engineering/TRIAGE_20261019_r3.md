## 3. D-18 closed — Windows benchmark audit hook

Root cause: Windows asyncio's ProactorEventLoop implements its self-pipe with
`socket.socketpair()`, which performs a loopback TCP connect and raises the same
`socket.connect` audit event as real traffic. The benchmark rejected it and aborted.
Fix: allow only loopback connects (`127.0.0.1`, `::1`, `localhost`), record them separately as
`allowed_loopback_attempts`, and keep raising for every external connect and for all
`socket.getaddrinfo` calls. Verification: `test_r4_performance_harness.py` PASSES with
`status = REAL_RUNTIME_VERIFIED` and `blocked_connect_attempts = 0`.

## 4. D-19 closed — project-retirement rollback under lock pressure

Root cause: transient Windows sharing violations (`WinError 5/32`) on project-directory
renames while other modules hold a handle. Fix: bounded retry helper `_rename_retry` used by
quarantine, restore and retirement renames; the original error is re-raised after the bounded
attempts so failure semantics do not change. Verification: the project-retirement suite passes
in isolation and the file is green in the targeted profile.
