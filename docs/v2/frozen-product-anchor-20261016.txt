# PoemSeed / AI-Novel-Studio V2：冻结产品决策与高级功能续开发锚点

版本：2026-10-16。性质：**用户已确认的目标与开发约束**，不是“所有功能已实现”的证明；请在 Dot/Hermia 会话中读取，并与 GitHub 最新源码核对。长期保存建议由 Hermia 写入该项目文档并维护版本化台账，不得替代用户的账户 Memory。

## 一、项目定位与不可改变的用户决策

1. **单一 Studio，模块独立、资产共享、连接可选。** 小说、剧本、图片、视频、音频、分镜、剪辑/导出应能各自启动、运行和输出；不能强制先有小说、导演或其他上游模块。项目创作意图/模板只影响推荐与布局，不是功能/权限开关。普通表单与专业创作图复用同一项目、素材、任务、审核、历史和授权 Owner；不能重建第二套权威数据或队列。
2. **专业级“无限画布 × 智能导演总控台”成为一项融合的高级核心能力。** ComfyUI 式空间编排，导演可作为可选总控节点，也可完全不放导演节点。导演与小说、角色、场景、Shot、分镜、图像、视频、音频、Timeline 等通过有类型、可预览、可撤销的连接协调，用户始终能自行编辑、跳过、切断、替换及独立导出。建议不等于执行；有成本/云端发送/覆写影响时必须依原权威逐项预检、授权和审核。
3. **全部 A、B、U 与其他高级能力属于 V2 补全范围。** 但不能以目录存在、历史报表打勾或 mock green 冒充成熟产品：复查每个功能的真实代码、挂载界面、权限/版本/恢复、运行证据和缺口，标记 DONE / PARTIAL / MISSING / BLOCKED / LOCAL_REQUIRED。沿依赖次序渐进实现，不重复已有能力。
4. **NSFW/Mature 双发行策略（冻结）：** V2 内部研发版可继续完成符合适用规则的成熟内容工程；公开 V2 只保留高级设置里的**置灰、不可交互的“NSFW／成熟内容（暂未开放）”前端占位**，无事件、无 API、无解锁入口。**公开发布包物理剥离全部专属 NSFW 后端、专属路由/API、服务、执行器、工作流、模型适配扩展及私有依赖**，不能靠灰色前端、隐藏开关、密码、加密或改配置重新激活。公共兼容词表/安全规则可留在标准核心中，但它们不构成运行中的 NSFW 模式。绝不删除或损坏用户项目与合法历史数据。内部 Mature 开发不是绕过平台规则、年龄保护或模型安全限制的许可证。
5. **本地优先与低授权依赖。** 尽量复用用户自己的 Ollama、LM Studio、ComfyUI、llama.cpp 等；检查来源/许可证/资源，无授权不得下载/安装模型。可选云端/接口必须每次明示费用、传出资料及权限，不准静默切换到付费服务。体验面向不同显存档位且如实报告目标机验收，云端测试不能伪装用户 Windows/RTX 5080 GPU 实测。
6. **版本与项目隔离。** PoemSeed Studio 与 QingJian 是两个独立仓库/产品；本任务只开发 Studio，预留冻结 PoemSeed Local Interop，不碰 QingJian。旧 V1 及已冻结主分支/正式发行与用户本机数据保持不变。代码先增量冻结，再完成全链路后做正式总体验收；每个开发切片仍必须立刻跑相关测试。

## 三、专业融合工作台必须补全的能力

### A. 真正的大空间创作画布（视图可扩展≠无限制执行）

现有 `frontend/src/creative/GraphCanvas.tsx`、`graphCanvasGeometry.ts`、`frontend/src/canvasops/` 支持节点拖动、平移、滚轮缩放、框选多选、端口选择/连接、撤销重做与保存。现有缩放 0.35～2.5，坐标 ±100,000，普通图典型 16 节点、媒体图典型 24 节点、约 40 连线，这是受限图，不可宣称真正无限画布。

目标：独立且持久化的空间画布视图（大范围平移/缩放、坐标稳定或重基）、网格/吸附、快捷键/命令搜索、画布 MiniMap、自动对齐和分组、折叠/嵌套、注释、多选拖拽、跨画布复制粘贴、撤销重做、来源变更影响预览、断网/重开恢复、无障碍/中文输入、媒体按需预览、精确 asset/version/digest 绑定；有界处理大图时的 viewport culling/LOD/虚拟化，先验证 >=1000 个**展示节点**的响应/内存，而不是直接将后台执行 DAG 的 16/24 节点安全预算抬高。专业创作图的**执行**仍按既有类型校验、资源预算、任务队列与审核执行，可把大画布拆成可复用子图；无导演也可独立生成或编辑。

### B. 智能导演“总控台”作为画布的可选节点与独立面板

复用 `DirectorWorkspace`、`AIDirectorPanel`、`DirectorPanel`、`DirectorIntent`、`ShotCard`、`StoryboardWorkspace`、原 `CreativeService`/Model Center/Review/Task。目标为可折叠导演总控节点（亦可展开专业面板），按项目/片段设置叙事目标、类型、时长、观众、风格、情绪、色彩、视效、机位景别/镜头运动、角色服装、场景/时间/灯光连续性、节奏、声音与资源预算。读取小说/剧本/角色/世界观/分镜/参考素材的**有权限的版本快照**，向多个模块提出有来源的、可视化差异建议，用户预览、选择、批准后才提交。允许多个可区分职责的导演子节点、独立场景子工作台；禁用/拆除导演不损害素材、其他模块或独立创作能力。

必须构建真实 Owner 级的建议→审批→产生正式 Shot/Prompt/素材任务或后期草稿→状态回传/失败解释→人工复核的可演示闭环。模型建议与本地确定性检查明确区分。不能默默执行模型、花钱、改稿或反复重试 UNKNOWN；导演是“协调层”，不是绕过权限的特权角色。

### C. 与全生产链结合

任选小说/剧本/图片/视频/音频为独立入口；连接后支持 Story/Character/Scene→Script/Director/Shot→Prompt/Image→Video/Audio→Timeline→Export 的可选可追溯链。节点参考只来自合法当前对象/版本；内容增量、Graph/asset/document 来源变化必须报告影响，不得默认覆盖。不能让导演成为所有流程的强制上游。
