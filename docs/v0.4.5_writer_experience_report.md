## IMPLEMENTED

- TipTap Selection range/text → Rewrite Request → Streaming Draft → Diff，AI 不直接覆盖正文。
- Chapter Tree 右键菜单：Rename、Duplicate、Delete（二次确认）、Move Up/Down。
- Duplicate 复制正文、Summary 与基础 metadata，不复制 Job/Version ID。
- Version Conflict Panel：Keep Local、Keep Server、Compare。
- 段落级 Original/Generated 展示及整段 Accept/Reject；全文/所选段落 Accept 安全边界保留。
- Novel Settings：JSON/Markdown Export；JSON/Markdown Import Preview，确认后创建新 Novel，冲突不覆盖。
- Pending Canon Card：Edit、Approve、Reject；编辑内容随审批进入 Canon。
- Save Indicator、离页未保存提醒。
- Chapter History：Version、Time、Source、Preview、确认 Restore。
- AI Accept 通过 ChapterRepository 写 `AI_ACCEPT` 版本历史。
- 修复日志不可写导致生成任务失败的生产 Bug；日志现在旁路降级。
