# Same-project graph reference templates

2026-10-18. Complements portable text templates with a bounded saved-source reference file for existing multimodal graphs. The file contract `poemseed-project-graph-reference/1` stores only the verified project instance/actor/scope, saved graph id/version/definition and execution digests, and selected node IDs. No prose, media bytes, provider configuration, token, approval or run state is stored in the file. Maximum actual UTF8 payload: 16,000 bytes.

Import checks the current project-instance/identity/branch before any source request. The original Studio overview is reread before and after the original Graph get, requiring the same current incarnation. The source must still match the pinned version/digests, be readable/editable through the original actor-private API, and have current selected references. The original copy planner then checks target schema, catalogue, typed edges and original limits, creates fresh IDs and stages an explicit local append. Original history, Save, source validation, preflight and execution approval remain authoritative.

Export requires a saved, unchanged source selection and an explicit local-file confirmation, then rereads that source before producing the file. Approval is single-use and bound to current owner/target/selection. Stale versions, missing sources, authority loss, cross-project/cross-incarnation files and incompatible target formats refuse rather than silently rebind. The source itself remains required; this reference file is not a self-contained cross-project media archive.

Evidence: 45 targeted contract/component/original-copy/original-workspace checks passed; TypeScript, production Vite build and shared token guard passed. A source-pinned image-graph fixture checks five nodes/four typed edges and retained original Asset pins, without invoking a provider. Actual source-generation rereads and stale-source/foreign-owner refusal are exercised through fixture transports. The initial TypeScript failure was a discriminated-scope narrowing error in this new helper; the source was corrected without relaxing comparisons or changing tests. Original failure retained.

Receipts/logs: docs/delivery/v2-development/graph-project-templates*. No new backend route, privilege, workflow engine, online marketplace, automatic generation or browser end-to-end acceptance is claimed. General cross-project media rebinding and reusable executable subgraphs remain pending.
