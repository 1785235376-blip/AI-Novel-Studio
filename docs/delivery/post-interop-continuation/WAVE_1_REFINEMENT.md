# Wave 1 source and navigation refinement

Scope: U08 explicit source addition, remaining U03 structured search, and U07 return to A02/A11 original model-opinion results. This extends the published Wave 1 checkpoint without a new context store, task executor, permission framework or shell layout.

## U08 actual source flow

The existing author preview now reads a catalogue of original Chapter, approved Canon, approved StoryGraph and Research paragraph sources. The author explicitly adds a pointer, fixes its original version/content digest and citation, chooses inclusion and a bounded character budget, then reviews the exact existing adapter request. No text supplied by the client becomes source authority. Catalogue reads do not generate; changes invalidate the existing preview receipt.

The original AuthorRequestScope, AuthorPreparer, JobManager and request assembler carry the additions. Every preview and actual adapter dispatch re-resolves pointers from their original services and rechecks actor, project, branch, flags, privacy, version, digest and citation. Missing/changed/revoked sources fail closed. Request scope persists; token-bearing resolver callbacks are transient. Completed output, diff/history reads and original task projection become unavailable after source, privacy or feature revocation, including reconstructed jobs after restart. Collaboration authority cannot downgrade into a local session.

NONE removes implicit manuscript and automatic context; manually added sources remain explicit independent author choices. Excluding a pinned addition also omits potentially dependent automatic and STYLE/PLOT references. The primary manuscript remains controlled separately. At most 16 additions, 8000 characters per addition and 32000 included source characters are accepted; truncation is visible in the actual-source manifest. Research remains untrusted RESEARCH, is never promoted to Canon, and is always LOCAL_ONLY. Nested original privacy restrictions cannot be waived by a permissive parent. Character-only requests reject added scope and never render the picker.

Original historical Canon records without numeric versions use exact content identity/digest rather than an invented version. No legacy records are migrated or rewritten. Existing requests without added_sources retain their earlier request and persistence contract. The source catalogue follows existing owner boundaries: collaboration branches without a native branch manuscript adapter explicitly cannot add Chapter records; Graph keeps its existing writer-only record authority. Research query uses its original literal search and can locate paragraph citations beyond the initial browse window.

## U03 and U07

Current owner lists resolve requestedJobId; missing targets do not select unrelated results.
