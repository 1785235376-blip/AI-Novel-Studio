# Known limitations and boundaries

Final gate status is tracked in RELEASE_READINESS and TEST_RESULTS; this file does not declare all tests passed.

- Real provider/model/GPU/audio/video inference and billing were not invoked. Native/OpenAI-compatible adapters are contract-tested, not universally vendor-certified. No paid budget or real credentials were used.
- Interactive Windows DesktopHost/WebView2, OS-vault persistence, Chinese IME and user acceptance remain separate from hosted compile/native-contract results.
- A fresh official-input BaseApplication, self-contained Host and complete unsigned internal acceptance ZIP have now been built and verified in hosted Windows CI. Native Python/PostgreSQL/pgcrypto/UTF-8 recovery and packaged-app imports passed at the recorded source revisions. WebView2 Evergreen and VC++ x64 are explicit external prerequisites; this is not a fully offline or signed public installer. Real clean install/upgrade/uninstall retention and interactive desktop acceptance remain NOT_RUN.
- ffmpeg/ffprobe processing is exercised when installed. They are not silently bundled or downloaded by production; Windows codec packaging and redistribution inventory remain a packaging boundary.
- Plugin execution remains DENY_ALL. Declarative package validation/install/rollback is distinct from a secure executable extension runtime; PR #26 was not merged.
- Visual references use lexical metadata search. No fake embeddings or claimed automatic visual-consistency model.
- Video assembly is a bounded silent 640×360 review output. Full NLE, soundtrack mastering and real generated-shot quality/consistency are not implemented by that path.
- Structured AI planning uses bounded chapter excerpts, strict schemas and exact evidence, then Draft review. Correct quotes do not prove literary/semantic correctness. Whole-book hierarchical autonomous planning is not claimed.
- The three workflow recipes produce review artifacts; real Agent nodes are controlled separately. Full autonomous Canon/manuscript/media application is not silently enabled.
- Creation/planning/workflow/asset metadata reuse durable sidecars in both backend profiles. Single-host locks are provided where implemented; distributed multi-host scheduler/lease semantics are not claimed.
- Source-policy revocation blocks not-yet-dispatched calls and invalidates later attempts. It cannot retract content already sent to a provider.
- Privacy migration treats historically lost/unknown policy conservatively. It cannot reconstruct restrictions that an old version discarded; authors must review unknown records explicitly.
- Candidate import applies individual repository transactions with durable checkpoints, not one global cross-entity transaction. Ambiguous interrupted writes require human review rather than blind overwrite.
- Target desktop screenplay/Word/EPUB-reader compatibility and final typography review remain distinct from independent parser/OOXML/PDF embedding checks.
- Local cloud Chromium was blocked before page launch by an OS socket restriction. Only completed exact-head hosted browser results may be counted as browser evidence.
