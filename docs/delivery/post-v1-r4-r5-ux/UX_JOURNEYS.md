First working journeys under implementation:
- U02: type Chinese/emoji → local draft status → delayed or failed save → retained text/export → reconnect and version conflict → explicit recovery without losing either candidate.
- U01: record current source-version/anchor and stopping note → close/reopen → reauthorize scope → restore only the current valid anchor or explain staleness.
- U03: keyboard search Chinese entity/chapter names → exact source/version → resolve and navigate; stale or denied sources produce no jump.
- U07: find the same existing task after reopening → inspect real stage/output/history; no time-driven fake percent and no implicit rerun.
- U12: explicitly preview diagnosis → deselect optional content → local sanitized export; no automatic upload.
