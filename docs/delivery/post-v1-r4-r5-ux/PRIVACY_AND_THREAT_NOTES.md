# Privacy and threat boundaries

Public repository: only original synthetic fixtures and sanitized bounded evidence may be committed. No prompts, original manuscripts, user paths, hardware identifiers, DSNs, tokens or keys belong in diagnostics or GitHub.

Backend actor/project/workspace/storyline/branch authority remains canonical. Writes require current source/version and appropriate permission. AI output remains Draft until explicit domain review; approval, Canon promotion, manuscript acceptance, export and cloud transmission are separate actions.

Templates/workflows are untrusted declarative data. No eval, dynamic import, scripts, executable plugins, permission grants or hidden network route is introduced. Executable extensions remain DENY_ALL. A local-looking endpoint is not sufficient proof of local inference.

Resume/search/diagnostics preserve origin privacy. Search count, cache, title and snippets must not leak inaccessible sources. A diagnosis is generated only by an explicit user action, previewed, and exported locally without upload. Missing real model/runtime capability remains unavailable rather than synthetic success.
