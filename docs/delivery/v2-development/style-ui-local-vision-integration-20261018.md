## Vision runtime, still unavailable to durable Director execution

An actual local Ollama HTTP adapter and original-registry IMAGE_UNDERSTANDING node
now exist. Explicit enable uses a domain-separated VISION identity and preserves
TEXT registrations. Numeric loopback, current original Model Center capability,
local-weight/hash and license evidence are required. Reads never probe.

One absolute asynchronous deadline and a 50ms authority watchdog cover metadata,
headers, uploads and raw response drips. Cancellation cancels and awaits transfer;
HTTP contexts close. No proxies/credentials/redirects/retries/fallback. Metadata
JSON rejects duplicate keys/nonfinite values/invalid shapes/recursion; Content-Length
conversion is bounded. Transport errors are normalized. Existing TEXT defaults remain.
Synchronous owner/decoder checks are not preemptible host work. Cancelling a client
request does not prove upstream inference stopped. No hardware/cost/quality estimate
is fabricated. Private Broker inventory explicitly returns
DIRECTOR_IMAGE_JOB_NOT_INTEGRATED. No durable IMAGE job, settlement, terminal,
pending review, adoption or executable Director API/UI is provided here.

All HTTP/model responses in verification were injected. No live Ollama/model service
was called. Official unversioned REST references and tested library versions are in
docs/development/local_vision_runtime_v3.md; live compatibility remains NOT_RUN.
