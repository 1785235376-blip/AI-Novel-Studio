# 醒于废墟



---

# 第2章

刺耳的尖啸撕裂了死寂，紧接着是某种沉重金属扭曲的轰鸣。林渊在剧烈的眩晕中睁眼，入目并非熟悉的天花板，而是高达百米的混凝土残垣，上面爬满了灰白色的变异苔藓，像是一只只窥视的眼睛。空气中弥漫着臭氧烧焦后的腥甜与腐烂金属的混合气味，每一次呼吸都带着铁锈的涩味。

他试图坐起，却发现手中紧紧攥着一枚破碎的银色芯片，边缘刻着早已失传的量子编码。这不是普通人的物品，而是他潜意识里最恐惧的烙印。林渊迅速环顾四周，这里是“记忆回廊”的入口，废弃的地铁隧道墙壁上投影着无数模糊的人脸，它们在空气中无声地尖叫、哭泣，随即被风吹散。这些不是幻觉，是这座被称为“新巴别塔”的城市在通过集体潜意识向他求救，或是……嘲弄。

“醒了？这可是个稀罕玩意儿。”

一个苍老而沙哑的声音打断了他的沉思。老陈坐在一台生锈的自动售货机后，那机器半嵌在倒塌的立柱中，指示灯诡异地闪烁着绿灯。老人手里夹着一根早已熄灭的烟斗，眼神浑浊却锐利，死死盯着林渊手中的芯片。

“那是旧时代的钥匙，”老陈缓缓说道，声音里透着深深的疲惫与警惕，“在这个地方，拥有钥匙的人往往意味着灾难的开端。”

林渊没有立刻回答，他的目光扫过隧道深处。那里的光线昏暗，但隐约可见城市的核心轮廓——一座巨大的、仍在微微搏动的反应堆结构。他心中涌起一股莫名的寒意。根据城市规则，核心从未真正关闭，它正以微弱的频率运转，维持着这座死城永恒的停滞。而他手中这块芯片，似乎正是控制频率的密钥。

“我记不起我是谁，”林渊的声音平静得可怕，只有他自己能听出那底下压抑的颤抖，“只知道我想弄清楚，为什么这座城市会陷入这种停滞。”

老陈冷笑一声，将烟斗在满是灰尘的地面上磕了磕：“停滞？那是‘回声’的杰作。它把所有人的记忆都锁在了过去，谁试图修复，谁就会被撕碎。”

话音未落，周围的空气突然凝固。那些墙壁上的人脸瞬间扭曲，无数破碎的画面强行涌入林渊的脑海：巨大的量子实验舱、失控的能量读数、以及一个被推下控制台的身影——那是他自己。画面戛然而止，伴随着一阵剧烈的头痛，仿佛大脑皮层被电流击中。

“别看了，”老陈厉声喝止，伸手按住林渊的肩膀，“那是‘回声’的反弹。你的记忆缺失不是偶然，是这城市为了掩盖真相而植入的防御。继续深究，你会疯的。”

林渊甩开老陈的手，低头再次审视手中的芯片。在昏暗的光线下，芯片表面浮现出一行微小的红色警告，与他此刻的心跳频率完全同步。毁城的源头，或许就藏在这枚小小的芯片里，而他自己，正是那个按下开关的罪魁祸首。但他不能停下，因为只要真相被掩盖，这座城市就永远不会迎来终结，也永远不会得到救赎。

“带我去废墟广场，”林渊站起身，眼中的恐惧逐渐被一种冷硬的执拗取代，“我要找到通往核心的路。”

老陈叹了口气，从售货机里掏出一瓶浑浊的水递给他：“路长着呢，小伙子。而且，小心别让那些‘回声’把你拉进过去。一旦你开始修复，我们就都得死。”

林渊接过水瓶，指尖触碰到冰冷的瓶身，心中默念：不管代价是什么，真相必须被揭开。
