# V0.7.0 Phase 3B Generation Safety Lifecycle Report

## Final Decision

`V0.7.0 PHASE 3B = PASS`

Phase 3B expands the existing read-only visual workflow into an author-facing explanation of the established generation safety lifecycle. It remains an observability layer only.

## Contract

- Contract version: `visual-text-workflow/v2`
- Contract remains read-only and rejects unknown DTO fields.
- Provider/model identity remains `(provider_id, model_id)`.
- Every node carries a stable production-boundary identifier; the primary UI displays Chinese explanations rather than internal identifiers.

## Lifecycle Mapping

| Author-facing stage | Existing production boundary |
|---|---|
| 隐私筛选上下文 | Context admission, privacy filtering, Context Snapshot policy |
| 文本模型 | Existing `TextModelNode` and provider-neutral registry identity |
| 流式生成 | Existing `generation.started/delta/completed/failed/cancelled` lifecycle and cancellation |
| 草稿与差异预览 | Generation Job output and existing diff calculation; no manuscript mutation |
| 显式采用 | Existing completed-job and optimistic-version checks in Accept |
| 创建新修订 | Existing authorized atomic `AI_ACCEPT` revision append; history remains immutable |

No runtime stage was replaced. TextModelNode, SSE, cancellation, Diff, Accept, revision, and restore contracts were not modified.

## Architecture and Security

- Alternate execution paths: 0
- Workflow write endpoints: 0
- Workflow persistence: none
- Database/schema/migration changes: none
- The existing trusted GET route resolves session, membership, scope, and permission before composition.
- Cross-workspace access remains denied.
- Composition reads only safe provider/model registry descriptors.
- No prompt or context content is included in the DTO.
- Capabilities are allowlisted and display labels are filtered for sensitive markers.
- No credential management, provider administration, fallback, or second provider was introduced.

## Frontend

- Semantic ordered content and a native textual details view preserve reading order and keyboard access.
- No Run, Save, Publish, Add Node, connection handle, or topology-editing control exists.
- Existing Panel, Badge, EmptyState, Lucide icons, and DS-v1.0 tokens are reused.
- No canvas primitive, shell geometry, global navigation pattern, token family, or protected-surface redesign was introduced.
