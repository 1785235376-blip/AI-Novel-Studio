## API implementation

The project-scoped Narrative Finding API now exposes:

```text
POST /api/projects/{project_id}/narrative/expectations
POST /api/projects/{project_id}/narrative/checks
GET  /api/projects/{project_id}/narrative/findings
GET  /api/projects/{project_id}/narrative/findings/{finding_id}
POST /api/projects/{project_id}/narrative/findings/{finding_id}/resolve
```

Expectation creation validates that its typed subject exists inside the route project. Cross-project subject, finding read, and finding resolve operations return project-scoped 404 responses.
