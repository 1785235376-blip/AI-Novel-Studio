## Safety and repeatability

- Uses isolated `ai_novel_studio_acceptance`; never drops or resets a database.
- Seed uses stable owned identifiers and conflict-safe inserts. Repeated starts preserve manual data.
- Session tokens are randomly generated per launch and stored only under ignored `.runtime`.
- Unknown port occupation fails closed; no unrelated process is killed.
- Shutdown uses recorded PID plus process-name verification and preserves data.
