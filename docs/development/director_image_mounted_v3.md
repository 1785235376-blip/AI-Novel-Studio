# Mounted Director IMAGE V3

This additive private workflow uses the original Creative, Asset, JobManager,
Broker, Model Center and document owners. It does not add an engine or store.
The authoring Graph Director console is the consumer; participant read-only
surfaces do not gain access.

## Explicit actions

The `/novels/{nid}/experimental/creative/director-image-v3` namespace provides
passive capabilities and actor-owned metadata list/status, and separate POST
preview, dispatch, cancel, prepare-review, declare-cost, review and adopt actions.
The browser supplies bounded selections and explicit consent inputs only.
Current actor/scope and Host authority are resolved by the original invoker and
trusted discovery Host resolver. Forwarded provenance is rejected.

Preview records exact source and saved existing DIRECTOR DRAFT scene pins, but
never calls a model. Dispatch uses the existing sealed IMAGE worker and Broker.
Unknown-estimate budget restrictions remain intact. No implicit budget changes,
model fallback, automatic retries or model calls on GET/reopen are introduced.
A registered local VISION IMAGE_UNDERSTANDING route is required.

Recovery metadata never includes source bytes, prompts, model output or historical
proof content. It is available to the current original Host/project owner when
execution flags are off or source/target pins have drifted. Cancellation only
signals a matching live sealed worker and does not claim upstream preemption.
Missing/restarted execution cannot be reconstructed from stored metadata.
Lost dispatch acknowledgements are resolved by reading the original proposal ID.

Current exact source/target remains mandatory for advice, cost declaration,
review and new adoption. Human cost declarations remain unmeasured and
unverified. Adoption adds a human-authored scene note through the original
revision owner; it does not replace source scenes or repin Graph selections.
Historical adoption metadata can be reopened without claiming present freshness.
PROMPT_ADOPTION_WRITE_ENABLED remains false.

## Verification boundaries

New mounted tests reuse File/real-PostgreSQL-parametrized original owner fixtures
and injected transports. No live model call, live inference quality proof,
PostgreSQL service startup, browser launch, release or main merge is performed
for this change. Browser launch was already known blocked in the task environment.

## Authoring UI and race controls

The authoring console now has an explicit IMAGE review panel. It captures the
original client's session/scope, and reads original Asset and registered VISION
choices only after the user opens it. Dispatch, cost declaration and human note
adoption have separate consent steps; the amount starts blank. Broker admission
failure points to the original budget settings through existing workspace leave
guards, without changing policy.

Private evidence is retired on context, source, target, selection, permission and
inactive transitions. Refresh clears old evidence before reading. Unsubmitted
cost/note text blocks destructive panel reads and unrelated console reads until
explicit clear/submission. A narrow synchronous IMAGE-intent selection fence
protects Graph click, Escape and node-directory changes without disabling normal
read-only selection. Lost command acknowledgements direct the user to explicit
same-proposal status/review; commands are never automatically replayed.

The final isolated backend mounted suite passed 16 File cases; its 16 real-PG
variants were prepared but not run by this worker. Earlier broader backend
regressions passed 141 cases before the three final metadata/cancellation cases
were added. Frontend source was independently reviewed, including real mounted
Graph selection and workspace Broker-navigation/discard tests. Production build,
TypeScript and UI token lint passed. These checks establish implementation
behavior with injected transports, not live inference or browser visual proof.
