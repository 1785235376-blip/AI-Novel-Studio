## Modified files

## Architecture changes

`STORAGE_BACKEND=file` now composes one shared File Bundle. API calls Services rather than concrete file functions. Context Pack is built from repository sources with unchanged output. JobManager calls Chapter/Context/Canon/Generation Services and contains no file writes. V0.1 `build_context(Path)` and `FileRepository` remain supported.

## Compatibility

- API paths, IDs and response structures are unchanged.
- File storage layout and atomic writes are unchanged.
- Old imports remain valid.
- `app.jobs.repo` remains as a composition-only compatibility facade for V0.3 tests; Job business logic does not use it.
- `postgres` does not fall back to File.
