## Closed Findings

### ACCEPTANCE-BLOCKER-001 — CLOSED

- SCENARIO: Alpha → Beta → Alpha → Empty → Alpha
- ACTION: Switch through production Workspace management.
- EXPECTED: AppShell remains mounted; trusted session remains; Empty shows child scope NONE.
- ACTUAL before fix: `novelId=''` triggered the top-level Connection page guard.
- ROOT CAUSE: `if (!s.novelId)` treated a valid workspace-only scope as disconnected.
- FIX: Connection page now appears only when both Novel and collaboration Scope are absent. Incomplete scope no longer calls branch bootstrap. ContextBar renders empty child values as `NONE`.
- RESULT: PASS in all four switch directions; no first-child selection.
- SCREENSHOT: `03_workspace_beta.png`, `04_workspace_empty.png`, `05_workspace_switch.png`

### ACCEPTANCE-HIGH-002 — CLOSED

- SCENARIO: Initial Novel/revision loading while trusted actor bootstrap completes.
- EXPECTED: Same-scope identity enrichment must preserve selected chapter.
- ACTUAL before fix: `setCollaboration` always cleared `chapterId`, causing editor/revision detail to disappear during loading.
- FIX: `setCollaboration` preserves `chapterId` only when Workspace/Project/Storyline/Branch are exactly unchanged; real scope changes still clear it.
- RESULT: Revision Detail and Restore PASS; trusted actor remains server-owned.

## Remaining UX / Productization Gaps

These are not functional BLOCKER/HIGH findings and were not broadened into a V0.6 implementation.

1. **UX high priority:** the ordinary no-session entry is still “连接协作项目” and asks for session token plus workspaceId/projectId/storylineId/branchId. This is acceptable as the current acceptance/debug bootstrap, but not a finished end-user login/navigation flow.
2. **Productization gap:** ContextBar and management panels expose internal slugs/IDs and terms such as Workspace, Storyline, Branch, Actor, DOMAIN_LEAD and DIRECT.
3. **Productization gap:** mixed Chinese/English labels remain across navigation, AI tools, revision reasons and authorization surfaces.
4. **UX:** dirty/conflict switching fails closed correctly but the management surface does not provide a strong, explicit explanation of why the click was blocked or the next safe action.
5. **Productization gap:** collaboration mode visibly says chapter creation is unsupported; the technical Novel capability exists, but the full product workflow belongs to the planned V0.6 consolidation.

Visual review also found substantial empty space in Empty Workspace and management-heavy surfaces that feel closer to an administration tool than a finished author workspace. DS-v1.0 remains frozen; no redesign was attempted.
