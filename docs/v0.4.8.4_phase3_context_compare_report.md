## Chapter Markdown Contract Fix

`document_to_markdown()` now defines one explicit EOF policy:

- Empty Document → empty string.
- Non-empty Document → blocks separated by one blank line and terminated by one blank line (`\n\n`).

The implementation constructs the required suffix directly. It does not use `rstrip()`, `trim()`, or comparison-time normalization.

File Chapter reads render their stored Document through the same function used by PostgreSQL. This makes the returned `content` a Document-derived canonical Markdown representation in both backends.
