# V0.7.0 Phase 3C Text Runtime Diagnostics Report

## Final Decision

`V0.7.0 PHASE 3C = PASS`

Phase 3C adds a provider-neutral, read-only explanation of whether the explicitly selected text route is ready. It does not configure, probe, repair, switch, execute, or persist runtime behavior.

## Contract

- Contract version: `text-runtime-diagnostics/v1`
- `visual-text-workflow/v2` remains unchanged.
- DTOs reject unknown fields with `extra=forbid`.
- Selected identity remains `(provider_id, model_id)`.
- Safe capability metadata is allowlisted.
- Prompt, context, credential, health-detail and arbitrary registry metadata fields are absent.

## Registry-Only State Model

Diagnostics read only existing `ProviderDescriptor` and `ModelDescriptor` values. They do not call `resolve()`, `health_check()`, `generate_text()` or `stream_text()`.

The deterministic state precedence is:

1. `NOT_CONFIGURED` — 未配置
2. `UNAVAILABLE` — 暂时不可用
3. `MODEL_DISABLED` — 模型已停用
4. `STREAMING_UNSUPPORTED` — 不支持流式生成
5. `READY` — 可用

Unknown providers/models fail explicitly without fallback. Non-TEXT models fail closed with `CAPABILITY_NOT_SUPPORTED` before state mapping and cannot be misclassified as ready.

Each state includes a fixed Chinese explanation and author action. No action mutates configuration or runtime state.
