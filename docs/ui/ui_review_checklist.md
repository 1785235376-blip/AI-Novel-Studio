# UI Review Checklist

- [ ] Uses the canonical AppShell and ModuleWorkspace contract
- [ ] Uses existing design tokens and shared primitives
- [ ] Adds no unnecessary raw colors, spacing, radius or shadow values
- [ ] Does not duplicate a primitive or create module-specific visual systems
- [ ] Preserves ModuleSwitcher and ContextBar placement
- [ ] Preserves sidebar, inspector and status-bar geometry
- [ ] Uses consistent typography, spacing, radius and Lucide icons
- [ ] Handles loading, empty, error and disabled states
- [ ] Preserves conflict, revision and authorization semantics
- [ ] Provides semantic controls, keyboard access, focus and labels
- [ ] Keeps light canonical theme and future dark-token compatibility
- [ ] Keeps NOVEL, IMAGE and VIDEO inside one product language
- [ ] Does not present placeholder capability as implemented
- [ ] Passes relevant unit, geometry and Playwright visual regression
- [ ] Includes a Design System Change Request for protected changes
