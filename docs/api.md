# API V0.3

Runtime：`GET /api/health|providers|models`。小说：`GET/POST /api/novels`、`GET/PUT/DELETE /api/novels/{id}`。章节：`GET/POST /api/novels/{id}/chapters`、`GET/PUT /api/chapters/{novel_id}:{number}`。资料：characters/locations/canon/foreshadowing/timeline/secrets。生成：`POST /api/generate/{continue|rewrite|polish|brainstorm|review}`，`GET /api/generation/{id}` 与 `/events`，cancel/accept/reject。Context：`GET /api/context-preview`。Canon：pending 列表、approve、reject。
